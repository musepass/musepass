# Code of Conduct

This project follows the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be direct about the work and decent to the people doing it. Technical
disagreement is welcome and expected — this repository is full of decisions that
were argued about — but contempt, harassment and personal attacks are not.

## Scope

Issues, pull requests, discussions and any other space where somebody is
participating in this project.

## Reporting

Use GitHub's private reporting to reach the maintainers (the same channel as
`SECURITY.md`), or open an issue if the matter is not sensitive. Reports are read
by the maintainers; enforcement is at their discretion and can range from a
private word to removing someone from the project.
