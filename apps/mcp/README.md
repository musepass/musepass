# apps/mcp

阶段 3 待做。远程 streamable HTTP MCP 服务，5 个工具：

| 工具 | 作用 | 需要主人确认 |
|---|---|---|
| `check_name` | 查可用性与合规，不可用时给 3 个建议 | 否 |
| `request_name` | 发起注册，返回主人确认链接（默认 15 分钟有效） | 是 |
| `get_status` | 查询确认与发放状态 | 否 |
| `draft_card` | 根据对话生成名片草稿 | 发布时需要 |
| `get_profile` | 读取任意名字的公开名片 | 否 |

硬性要求：

- 每个工具先返回一句大白话结论，再返回结构化数据（复用 API 的 `summary` 约定）
- AI 只能发起和起草，**生效必须主人签名**，确认页要显示发起方是哪个 AI
- 工具描述里明确写「注册需要主人确认，请把链接交给主人」
- 同一主人、同一 AI 的频率限制

阶段 3 的签名复用 `POST /v1/names/claim`，AI 不需要也不能接触主人私钥。
